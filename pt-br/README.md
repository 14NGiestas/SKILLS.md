## 💡 Diretrizes de Execução
- **Rastreabilidade Teórica:** Todas as skills exigem fundamentação com os autores originais (ex.: Bardin, Freire, Minayo, Paro).
- **Separabilidade de Voces:** Mantém-se distinção rigorosa entre a síntese fiel do autor analisado e a apreciação crítica do pesquisador.
