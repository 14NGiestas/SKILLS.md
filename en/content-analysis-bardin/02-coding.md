# Bardin: Coding and Material Cutout

Skill to operationalize Step 4 (Coding) of Phase 2 (Exploration of Material) in Laurence Bardin's Content Analysis (2011/2016). Transforms raw material into organized analytical data using units of recording and counting.

## When to Use

- Following completion of Pre-Analysis and approval of the research corpus.
- To technically define the Recording Unit (RU) and Context Unit (CU).
- To establish formal enumeration rules (frequency, presence/absence, intensity).
- To segment, code, and map raw text excerpts with direct traceability.

## Steps of Coding

### 1. Defining Analytical Units
- **Recording Unit (RU):** Choose the baseline segment for analysis (word, theme, sentence, character, or event). For thematic analysis, the standardized RU is a statement or idea regarding a given subject.
- **Context Unit (CU):** Define the broader surrounding segment (paragraph, full answer, or text passage) that provides exact meaning to the RU.

### 2. Establishing Enumeration Rules
Define the measurement metric for RUs across the corpus:
- **Absolute/Relative Frequency:** Simple count of occurrences.
- **Presence/Absence:** Binary tracking of theme existence within a document.
- **Weighting/Intensity:** Assignment of weights based on emphasis or enunciation tone.

### 3. Segmenting and Coding Passages
- Analyze documents and extract each occurrence of the RU.
- Assign a unique alphanumeric code to each content segment.
- Link each code to its corresponding literal citation and location (document, page, line, or participant ID).

### 4. Generating the Raw Matrix of Recording Units
Build a structured coding matrix containing:
- RU Code
- Verbatim Excerpt Text (Textual evidence)
- Context Unit (Associated CU)
- Metric/Frequency
- Corpus Location (Doc ID)

## Gotchas

- **Confusing RU with CU:** The RU is the core unit of meaning sought; the CU is the surrounding context required to prevent the RU from losing its actual meaning.
- **Disconnecting Codes from Raw Text:** Every created code must retain a direct link to the original citation to prevent loss of evidence during defense.
- **Changing Enumeration Rules Mid-Process:** Maintain the same metric defined in the protocol across the entire corpus.
